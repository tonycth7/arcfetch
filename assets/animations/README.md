# Bundled animations

These frame sets come from [animfetch](https://github.com/Andrew-Velox/animfetch)
(MIT, Copyright (c) 2026 Mohabbat) and are embedded by `build.rs`.

One directory per animation, one `.txt` file per frame, filename order. Add a
directory here, rebuild, and it appears in `arcfetch --list-animations`.

A user directory of the same name under `~/.config/arcfetch/animations/`
overrides the bundled set.
