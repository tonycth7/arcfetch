# Example presets

These JSONC layouts are adapted from [fastfetch](https://github.com/fastfetch-cli/fastfetch)'s
`presets/examples`, which is MIT licensed:

    Copyright (c) 2021-2023 Linus Dierheimer
    Copyright (c) 2022-2026 Carter Li

Comments were dropped and modules arcfetch does not collect were removed, so
the same files work with either tool.

Load one for a run with `arcfetch --preset 2`, or copy it into
`~/.config/arcfetch/` to keep it.
